<h1>YouTube Comment Analysis: Car Category Sentiment and Topic Extraction</h1>
This project focuses on collecting and preprocessing YouTube comments from various car-related videos to prepare them for sentiment analysis.</br>
It categorizes comments based on vehicle types (SUV, Sedan, Hatchback, Coupe) and uses advanced Natural Language Processing (NLP) techniques to clean and normalize the text data.

<h2>Data</h2>
The dataset is generated by fetching comments directly from the YouTube Data API v3 based on specific video URLs representing different automotive categories.
</br>
Raw Data: fetched_yt_comments.csv
</br>
Cleaned Data: organized into multiple preprocessing schemes under "data/".
</br>
Features: Video ID, Video Title, Author, Raw Comment, Likes, Publication Date, and Category (SUV, Sedan, Hatchback, Coupe).

<h2>Important processes on the data</h2>
Text Normalization: The cleaning process converts emojis into text descriptions (e.g., :grinning_face:) and identifies strong punctuation patterns for further analysis.
</br>
Cleaning Pipeline: The system uses SymSpell for spelling correction and WordNetLemmatizer for reducing words to their base forms while preserving sentiment-heavy words like "not", "never", and "but".
</br>

<h2>Getting Started</h2>
First get an API key to download data from Youtube if you want to change the videos, but regardless, the data is provided in the repo.
</br>
Run the "progress.ipynb" notebook to execute the full pipeline.
</br>
For the SOTA analysis, run the "sota.ipynb" notebook in the sota comparison folder.
</br>
For deployment, Run the deploy.py script in the deploy folder.
</br>
nearly all sorts of data files are provided, meaning you can start at any stage you like because the repo already has the data, clean data, representations, model, sota model, etc. 
</br>
Results in text format are in the results folder and the visualizations for the sota comparison is in the "sota comparison/pictures" directory.
To fetch data, ensure your .env file contains a valid API_KEY.
</br>
Ground-truth sentiment labels were generated using LLM-assisted annotation, with manual review used to resolve ambiguous cases and label conflicts, if you change the data, be sure to attach the ground truth to it by whichever way you prefer.
</br>
</br>

<h2>Notes</h2>
API Limits: YouTube API has daily quota limits; the script includes a "category limit reached" check to prevent over-fetching.
The comments in the dataset are only those at the root level, so for example a comment that's a reply to another comment isn't included
